PostgreSQL

PostgreSQL is supported via the lib/pq driver. It offers the richest type system of the first-class drivers, including jsonb, arrays, sequences, and PostGIS geometry.

Connection

config := neat.DBConfig{
    Default: "postgres",
    Connections: map[string]neat.ConnectionConfig{
        "postgres": {
            Driver:   "postgres",
            Host:     "127.0.0.1",
            Port:     5432,
            Database: "test",
            Username: "test",
            Password: "test",
            SSLMode:  "disable", // disable | require | verify-ca | verify-full
            Schema:   "public",  // sets search_path
        },
    },
}

The DSN is built in key/value form: host=... port=... user=... password=... dbname=... search_path=public sslmode=disable. The Schema field maps to search_path, and Timezone maps to the TimeZone connection parameter.

Driver-Specific Options

  • Schema - PostgreSQL schema, defaults to public, sets search_path
  • SSLMode - disable, require, verify-ca, or verify-full
  • Timezone - sets the session TimeZone

Placeholder Format

PostgreSQL uses numbered placeholders $1, $2, $3, ... The placeholder index is generated from the bind position.

Quirk: PostgreSQL has no tinyint or mediumint. tinyInteger maps to smallint and mediumInteger maps to integer. Code that relies on exact storage width should account for this.

Quirk: Auto-increment is implemented via the serial family (serial, smallserial, bigserial) which implicitly creates a sequence. useCurrent() sets DEFAULT CURRENT_TIMESTAMP; PostgreSQL has no native ON UPDATE CURRENT_TIMESTAMP, so useCurrentOnUpdate() requires a trigger to be effective.

Quirk: json and jsonb are distinct types. jsonb is binary, indexable, and the recommended choice for new columns. enum is emulated with a check constraint rather than a native PostgreSQL enum type, which avoids the catalog management overhead of CREATE TYPE.

Quirk: Geometry types require the PostGIS extension. geometry columns accept an optional SRID via addSrid; typed variants like geometry(LineString) are emitted when the blueprint calls the matching method.

Behavior Notes

  • Schemas: Tables are created in the schema named by search_path. Set Schema in the connection config to target a non-default schema.
  • Identifiers: PostgreSQL lowercases unquoted identifiers. Mixed-case table or column names must be quoted; Neat ORM quotes identifiers automatically.
  • Transactions: Full BEGIN/COMMIT/ROLLBACK support with savepoints.
  • Locking: LockForUpdate() emits FOR UPDATE; SharedLock() emits FOR SHARE.

CockroachDB Compatibility

CockroachDB speaks the PostgreSQL wire protocol and uses the postgres driver. Point it at a CockroachDB node the same way you would point it at PostgreSQL:

Connections: map[string]neat.ConnectionConfig{
    "cockroach": {
        Driver:   "postgres",
        Host:     "127.0.0.1",
        Port:     26257,
        Database: "defaultdb",
        Username: "root",
        Password: "",
        SSLMode:  "disable",
        Schema:   "public",
    },
}

Differences to be aware of:

  • CockroachDB's serial defaults to unique_rowid(), which produces non-sequential 64-bit IDs. Do not assert on ordered IDs.
  • Some PostgreSQL functions and catalog views are not supported. Schema introspection may behave differently.
  • PostGIS is not available; geometry types will fail to create.

YugabyteDB Compatibility

YugabyteDB is PostgreSQL-compatible and uses the postgres driver. Connection setup is identical to PostgreSQL. YugabyteDB supports distributed transactions and the standard PostgreSQL feature set with some catalog differences.

Default Ports

  • PostgreSQL: 5432
  • CockroachDB: 26257
  • YugabyteDB YSQL: 5433
