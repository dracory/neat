Oracle

Oracle Database is supported via the pure-Go sijms/go-ora/v2 driver. The schema builder uses Oracle's NUMBER-based typing, CLOB for large text, and SDO_GEOMETRY for spatial data.

Connection

config := neat.DBConfig{
    Default: "oracle",
    Connections: map[string]neat.ConnectionConfig{
        "oracle": {
            Driver:   "oracle",
            Host:     "127.0.0.1",
            Port:     1521,
            Database: "XE",     // service name
            Username: "system",
            Password: "oracle",
        },
    },
}

The DSN is built as oracle://user:pass@host:port/service. The Database field holds the service name (e.g. XE, ORCLPDB1). Validation requires Host and Database.

Driver-Specific Options

  • No driver-specific options are currently exposed on ConnectionConfig. Advanced connection modes (TNS, LDAP, wallets) require passing a Dsn directly.

Placeholder Format

Oracle uses numbered placeholders :1, :2, :3, ... The placeholder index is generated from the bind position.

Quirk: Oracle has no native boolean, integer, or JSON types. Booleans become number(1), all integers become NUMBER(p) with a precision chosen to fit the value range, and JSON becomes CLOB. Application code must convert between Go types and these representations.

Quirk: dateTimeTz, timeTz, and timestampTz all map to plain timestamp. Oracle's TIMESTAMP WITH TIME ZONE is not currently emitted by the grammar; timezone handling is the application's responsibility.

Quirk: All spatial types map to SDO_GEOMETRY. This requires the Oracle Spatial option to be installed and licensed. Without it, CREATE TABLE will fail for any blueprint that uses spatial columns.

Quirk: enum is emulated with a check constraint on a varchar2(20) column. The 20-character width is fixed by the grammar; longer enum values will be truncated.

Behavior Notes

  • Identifiers: Oracle treats unquoted identifiers as uppercase. Neat ORM uppercases identifiers when emitting PL/SQL blocks for DROP ... IF EXISTS operations because the go-ora driver mishandles double-quoted identifiers inside EXECUTE IMMEDIATE strings.
  • Auto-increment: Oracle has no AUTO_INCREMENT keyword. Auto-incrementing columns use GENERATED BY DEFAULT AS IDENTITY, which automatically makes the column NOT NULL. The grammar skips the explicit NOT NULL modifier for identity columns to avoid ORA-01442.
  • Foreign keys: Oracle does not support ON UPDATE clauses on foreign keys. The grammar emits only ON DELETE. ON UPDATE CASCADE must be implemented with triggers.
  • Column changes: For ALTER TABLE ... MODIFY operations, the grammar skips NOT NULL modification to avoid ORA-01442. Set nullability correctly at CREATE time.
  • ON UPDATE CURRENT_TIMESTAMP: Oracle has no native ON UPDATE clause for column definitions. useCurrentOnUpdate() is a no-op in the generated DDL; use a trigger to update the column on row change.
  • Unsigned integers: Oracle has no unsigned integer types. The unsigned() modifier is a no-op.
  • Drop view if exists: The schema layer uses a check-then-drop approach because go-ora cannot execute PL/SQL anonymous blocks via Exec().

  • Oracle listener: 1521
