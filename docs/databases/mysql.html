MySQL

MySQL is the primary SQL backend for Neat ORM and the reference dialect for the MySQL wire protocol. The same driver works against MariaDB and TiDB.

Connection

config := neat.DBConfig{
    Default: "mysql",
    Connections: map[string]neat.ConnectionConfig{
        "mysql": {
            Driver:   "mysql",
            Host:     "127.0.0.1",
            Port:     3306,
            Database: "mydb",
            Username: "root",
            Password: "root",
            Charset:  "utf8mb4", // default
            Loc:      "Local",
        },
    },
}

The DSN is built as user:pass@tcp(host:port)/db?charset=utf8mb4&parseTime=true&loc=Local. Neat ORM always sets parseTime=true so that DATETIME and TIMESTAMP columns scan into time.Time instead of []uint8.

Driver-Specific Options

  • Charset - character set, defaults to utf8mb4
  • Loc - locale setting, URL-encoded into the DSN

Placeholder Format

MySQL uses positional ? placeholders. The same placeholder is reused for every bind position.

Quirk: dateTimeTz and timestampTz map to the same types as their non-Tz counterparts. MySQL does not have a separate timezone-aware type; timezone handling is controlled by the session timezone and the Loc DSN parameter.

Quirk: jsonb is treated as an alias for json. MySQL has no binary JSON type; both blueprint calls produce a json column.

Quirk: Spatial types accept an optional SRID suffix when WithSrid(n) is set on the column. MySQL 8.0+ enforces SRID compatibility for spatial operations.

Behavior Notes

  • Foreign keys: DropAllTables wraps the drops in a transaction and emits SET FOREIGN_KEY_CHECKS=0 before and SET FOREIGN_KEY_CHECKS=1 after.
  • Auto-increment: IDs are sequential and assigned by the engine. Tests can assert on ordered IDs.
  • Collation: MySQL 8 defaults to utf8mb4_0900_ai_ci (case-insensitive). Comparisons in WHERE clauses are case-insensitive unless the column collation is _bin or _cs.
  • Default timestamps: useCurrent() sets DEFAULT CURRENT_TIMESTAMP and useCurrentOnUpdate() sets ON UPDATE CURRENT_TIMESTAMP. Both are supported natively.

MariaDB Compatibility

MariaDB speaks the MySQL wire protocol and is nearly 100% compatible. Use the mysql driver as-is:

Connections: map[string]neat.ConnectionConfig{
    "mariadb": {
        Driver:   "mysql",
        Host:     "127.0.0.1",
        Port:     3306,
        Database: "mydb",
        Username: "root",
        Password: "root",
    },
}

Minor differences to be aware of:

  • MariaDB's JSON type is implemented as a LONGTEXT with a check constraint, not a true binary JSON column. Reads still return the JSON text.
  • Some utf8mb4_0900_ai_ci collations introduced in MySQL 8 are not available in older MariaDB releases.
  • MariaDB supports RETURNING on DELETE and UPDATE; Neat ORM does not currently use this feature.

Default Ports

  • MySQL / MariaDB: 3306
  • TiDB (MySQL protocol): 4000 - see the TiDB page for divergences
