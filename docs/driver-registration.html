Driver Registration

This document describes how to register and use database drivers in Neat ORM.

Supported Drivers

Neat ORM ships with 12 first-class drivers, including traditional wire-protocol databases, cloud/edge storage, and embedded/flat-file sources:

  • MySQL (wire protocol) — also drives MariaDB and TiDB
  • PostgreSQL (wire protocol) — also drives CockroachDB and YugabyteDB
  • SQLite (embedded, file-based or in-memory)
  • SQL Server (wire protocol)
  • Oracle (wire protocol)
  • Turso (edge / cloud, libsql protocol)
  • Azure Table Storage (cloud NoSQL) — see Azure Table Storage driver
  • Array (in-memory) — query Go slices as tables; see Array driver
  • CSVDB (embedded) — CSV directory as database; see CSVDB driver
  • GODB (in-memory) — Go data compiled into the binary; see GODB driver
  • JSONDB (embedded) — JSON/JSONL/NDJSON directory; see JSONDB driver
  • XMLDB (embedded) — XML directory; see XMLDB driver

Compatible Databases

The following databases are compatible with existing drivers and should work out of the box:

  • MariaDB with MySQL driver - nearly 100% compatible, same protocol
  • TiDB with MySQL driver - very high MySQL compatibility
  • CockroachDB with PostgreSQL driver - high PostgreSQL compatibility
  • YugabyteDB with PostgreSQL driver - high PostgreSQL compatibility

Driver Configuration

Drivers are configured in the DBConfig struct:

config := neat.DBConfig{
    Default: "default",
    Connections: map[string]neat.ConnectionConfig{
        "default": {
            Driver:   "mysql",
            Host:     "localhost",
            Port:     3306,
            Database: "mydb",
            Username: "user",
            Password: "password",
        },
    },
}

Driver-Specific Options

MySQL

  • Charset: Character set (default: utf8mb4)
  • Loc: Locale setting

PostgreSQL

  • Schema: Database schema (default: public)
  • SSLMode: SSL mode (disable, require, verify-ca, verify-full)
  • Timezone: Timezone setting

SQL Server

  • No specific options currently supported

SQLite

  • Database file path

Turso

  • Database URL
  • Auth token

Azure Table Storage

  • Dsn: Azure Storage connection string containing AccountName, AccountKey, and TableEndpoint

Custom Drivers

Drivers implement a common Driver interface. The built-in drivers are instantiated by a switch statement in database/orm based on the Driver field of ConnectionConfig:

type Driver interface {
    Open(dsn string) (*sql.DB, error)
    Close(db *sql.DB) error
    Ping(ctx context.Context, db *sql.DB) error
    BeginTx(ctx context.Context, db *sql.DB, opts *sql.TxOptions) (*sql.Tx, error)
    Placeholder(n int) string
    Dialect() string
}

To add a custom driver, implement the Driver interface and add a case to the createDriver function in database/orm/orm.go. There is no runtime registration API — driver selection is resolved at connection time from the config.
